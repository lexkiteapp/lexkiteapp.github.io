# Đăng video giới thiệu lên YouTube

File: `lexkite-promo-en.mp4` (bản dùng chung cho Chrome Web Store) và `lexkite-promo-vi.mp4`; ảnh bìa `lexkite-thumb-<mã>.jpg`.
Sinh bởi workflow "Video giới thiệu add-on" (`scripts/store-video.mjs`), bản gốc ở nhánh `store-video`.

## Cách đăng (anh tự làm – cần đăng nhập kênh YouTube)
1. https://studio.youtube.com → **Tạo (Create) → Tải video lên** → chọn `lexkite-promo-en.mp4`.
2. Dán Tiêu đề / Mô tả / Thẻ bên dưới; Hình thu nhỏ: tải `lexkite-thumb-en.jpg` (kênh cần xác minh số điện thoại mới đổi được ảnh bìa).
3. Đối tượng: **Không, nội dung này không dành cho trẻ em**.
4. Chế độ hiển thị: **Công khai** (tốt cho SEO) hoặc **Không công khai** (chỉ ai có link mới xem) – Chrome Web Store dùng được cả hai, **không** dùng Riêng tư.
5. Chép link `https://www.youtube.com/watch?v=…` → dán vào ô **Global promo video** trên dashboard (bản vi → ô *Localized promo video* của Tiếng Việt).
