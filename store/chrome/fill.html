Summary (≤132 characters):
Double-click any word for IPA, audio and meaning. Translate selections, save words with context, review with spaced repetition.
Description:
Lexkite turns everything you read and watch online into vocabulary practice for IELTS, TOEIC and everyday English – then reminds you to review each word right before you forget it.

LOOK UP ANY WORD, ON ANY PAGE
• Double-click a word: British & American IPA, audio, meanings by part of speech, definitions, examples and a picture.
• Select a sentence or paragraph: instant translation, with the grammar structures in it explained.
• Right-click → "Look up" or "Translate selection".
• Optional: explain an expression in depth with AI (Chrome's built-in on-device AI, or your own free Gemini key).

LEARN FROM YOUTUBE
• Turn on English subtitles and tap any word in the captions – the video pauses and you see the meaning and a translation of the whole line.
• Keys A / S / D jump to the previous, current or next subtitle line.

SAVE WORDS WITH THEIR CONTEXT
• Every saved word keeps the sentence and page where you found it.
• Words you have already learned are highlighted on the pages you visit (optional), so you review them in real context.
• Academic B2–C2 words can be underlined (optional).

REVIEW AT THE RIGHT MOMENT
• Spaced repetition with the FSRS algorithm (like Anki).
• Daily reminder and "golden moment" alerts when words are about to be forgotten, with quiet hours.
• A vocabulary card on every new tab (can be turned off in one click).
• Badge showing how many cards are due today.

A FULL STUDY APP INCLUDED
• 6,000+ words with IPA, topic word lists, the Academic Word List, phrasal verbs, idioms and collocations.
• Flashcards, games, listening & dictation, pronunciation practice, reading passages, IELTS & TOEIC practice tests with explanations.
• Interface in 15 languages.

FREE AND PRIVATE
• Free, no ads in the extension, no account required.
• Your learning data stays in your browser. Sign in with Google on lexkite.com only if you want to sync between devices.
• We never collect your browsing history or sell your data. Privacy policy: https://lexkite.com/privacy

5. Privacy practices

Single purpose
Lexkite helps users learn English vocabulary while browsing: look up and translate words or text the user selects on any web page, save them with their context, and review them with spaced-repetition flashcards, reminders and a vocabulary card on the new tab page.
storage
Stores the user's saved words, review schedule, progress and settings locally in the browser so the flashcards work offline and persist between sessions.
alarms
Schedules the daily study reminder chosen by the user and a 15-minute check that updates the badge with the number of cards due and detects words about to be forgotten.
notifications
Shows the daily study reminder and the optional "golden moment" review reminder. Both can be turned off and respect quiet hours set by the user.
contextMenus
Adds "Look up with Lexkite" and "Translate selection" to the right-click menu when the user has selected text.
scripting
After installation or an update, injects the extension's own bundled content script into tabs that were already open so word lookup works without reloading them. On youtube.com it reads the caption track list of the video being watched so the user can tap words in the subtitles. No remote code is executed.
search
The new tab page provided by the extension contains a search box; chrome.search.query sends the user's query to their default search engine instead of hard-coding a provider.
Host permission justification (http://*/*, https://*/*)
The core feature works on any web page the user reads: double-click a word or select text to see its meaning or translation, save it with the sentence it appears in, optionally highlight words the user has already learned, and tap words in YouTube subtitles. The same permission lets the background service worker call the dictionary and translation services listed in the privacy policy (Google Translate, Free Dictionary API, Wiktionary, Tatoeba, Datamuse, MyMemory, Openverse, and the user's own Gemini key if provided) and lexkite.com for optional sync. Page content is processed locally; only the word or text the user chooses is sent to those services.
New tab override (chrome_url_overrides)
Shows one vocabulary flashcard from the user's own saved words each time a new tab opens, with a search box using the default search engine. It can be disabled from the card itself or from the extension settings.
Test instructions (Notes for the reviewer)
