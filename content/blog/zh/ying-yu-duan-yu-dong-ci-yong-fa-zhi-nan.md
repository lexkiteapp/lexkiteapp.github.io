短语动词和单个动词的区别，首先是语体：*put off*、*look into*、*carry out* 多见于口语、日常邮件和一般叙述，*postpone*、*investigate*、*conduct* 则更常见于正式报告和书面表达。其次，两者的意思往往只是接近，并不能处处互换，有些短语动词甚至没有对应的单个动词。本文先给出对照，再说明中文母语者最容易在哪里选错，最后用几组改写练习帮你把语体感练出来。

如果你想先学短语动词本身的小品词意思和宾语位置，可以先看另一篇 [英语常用动词短语](/zh/blog/ying-yu-dong-ci-duan-yu-phrasal-verbs/)。这篇不再重复那些内容，只讨论“该选哪一个”。

## 短语动词和单个动词的区别，首先在口语感与正式感

英语里很多意思都有两套说法：一套来自日常的短小动词加小品词，另一套是较长的单个动词，其中不少源自拉丁语和法语，所以看上去更“书面”。汉语其实也有类似的现象，比如口语说“搞清楚”“弄坏”，书面语会写“查明”“损毁”。理解了这一点，就不会简单地觉得“单词更高级”。

{{diagram: d1 | 同一个意思的两种说法：左边偏口语，右边偏正式}}

下面这张表再多放几组，括号里是中文意思：

| 短语动词 | 单个动词 | 说明 |
| :--- | :--- | :--- |
| put off（推迟） | postpone | 口语说 put off，通知公告里常见 postpone |
| look into（调查） | investigate | 报告、新闻里多用 investigate |
| set up（成立） | establish | *establish a reputation* 不能说 set up a reputation |
| go up（上涨） | rise / increase | 说价格“涨了”，口语 *Prices went up* |
| bring up（提出） | raise | *raise a concern* 在会议和书面里更常见 |
| put up with（忍受） | tolerate | tolerate 常用于较客观的描述，如 *tolerate high temperatures* |
| make up for（弥补） | compensate for | compensate for 带有“补偿”的意味 |
| get over（克服、恢复） | overcome | *overcome a difficulty*，也可 get over a cold |

注意，表里每一行都只是“常见情况”，没有一条绝对规则。语体取决于场合、读者和你想表达的态度。

### 语体选择的三个小问题

1. 谁会读？给朋友发消息、写邮件给同事，通常用短语动词更自然；写公告、报告、论文，倾向于单个动词。
2. 要不要精确？*find out* 是“得知某个信息”，*discover* 是“首次发现原先不为人知的东西”，两者不总能互换：*I found out when the train leaves*，不会说 *I discovered when the train leaves*。
3. 搭配是否固定？有些单个动词有固定搭配，如 *conduct an experiment*、*establish a company*，选哪个，要看搭配而不是只看语体。

## 意思不完全一样：别拿同义词表硬换

最容易出问题的一类是，学习者把短语动词和单个动词当作可以互相替换的同义词。下面三组说明为什么不行。

**give up 与 abandon。** *give up smoking*（戒烟）很自然，*abandon smoking* 就不对。*abandon* 的意思是把人或物丢下不管，如 *abandon a car*，或者彻底放弃一项计划。*give up* 的范围更宽，可以放弃习惯、希望和尝试。

**set up 与 establish。** *set up a company* 和 *establish a company* 都说得通，但 *establish a reputation*、*establish the cause* 只能用 *establish*；*set up* 偏重动手安排或搭建，如 *set up a tent*、*set up an account*。这类固定搭配也可以对照 [雅思高分学术搭配词 Collocations 指南](/zh/blog/ya-si-da-pei-collocations-ti-fen-zhi-nan/) 来判断哪个更常见。

**carry out 与 conduct。** *carry out a survey* 与 *conduct a survey* 差别很小，这一组基本可以互换，只是 *conduct* 更正式，同时也有 *conduct an orchestra* 这类别的意思。

还有一批短语动词，几乎没有简洁的单个动词与之对应，如 *get along with*（与……相处）、*end up*（最终落到某种处境）、*hang out*（闲逛、聚在一起）。遇到这种情况，不必强行找“高级词”，保留短语动词就是最好的选择。

## 中文母语者最常见的四类选择错误

### 1. 在单个动词后面多加一个小品词

汉语的动词常常要靠补语或介词才显得完整，所以会把这个习惯带进英语：

- *discuss about the plan* → *discuss the plan*
- *mention about the problem* → *mention the problem*
- *enter into the room* → *enter the room*
- *return back to Beijing* → *return to Beijing*（return 已含“回”的意思）

这些单个动词本身就包含了方向或对象，不需要再补小品词。

### 2. 口语里全部使用“大词”

有些人认为词越长越高级，于是在日常对话里说 *I will purchase some water and visit the supermarket.* 语法没有错，但听起来像在读公告。换成 *I'm going to the store to pick up some water.* 自然得多。

### 3. 学术写作里堆口语短语动词

在较正式的书面表达里，*The experiment turned out badly, so we looked into the reasons* 读起来偏随意。*The experiment was unsuccessful, so we investigated the causes* 更合适。这不是说学术写作里一个短语动词都不能出现，而是要有取舍，尤其是 *put up with*、*get away with* 这类口语味很重的搭配。

### 4. 凭汉语趋向补语去猜小品词

汉语的趋向补语让人容易凭字面去猜小品词，但 *give up*（放弃）、*put up with*（忍受）、*look up*（查找）里的小品词并不是字面的方向。这类搭配只能按整块记下来：*look up a word* 是“查单词”，不是“向上看一个词”。

## 改写练习：同一句话，换一种语体

下面五句是偏口语的说法，试着改成较正式的版本；想系统练习同义替换，可以读 [雅思同义替换与 Paraphrase 技巧](/zh/blog/ya-si-tong-yi-ti-huan-paraphrase-ji-qiao/)。

1. *They set up a new committee last month.*
2. *Prices have gone up again.*
3. *The manager looked into the problem.*
4. *I can't put up with this heat.*
5. *She brought up an interesting point.*

参考答案（不是唯一的）：

1. *A new committee was established last month.*
2. *Prices have risen again.*
3. *The manager investigated the problem.*
4. *I cannot tolerate this heat.*
5. *She raised an interesting point.*

再反过来练：把 *Please note that the event has been postponed* 改成对朋友说的话，可以是 *We've put the party off till next week.* 两个版本都对，只是对象和场合不同。

## 看一个完整的例子：同一件事写给两个人

假设会议要改期（写邮件时的语气选择，另见 [商务英语邮件格式](/zh/blog/shang-wu-ying-yu-you-jian-ge-shi/)）。写给同组同事，可以这样说：

> *Hi Sam, we need to put off Friday's meeting. Something has come up with the client, and I'm still trying to find out how long it will take to sort out. I'll let you know as soon as I can.*

写给部门负责人和外部客户的通知，则更常见这样的版本：

> *Dear all, Friday's meeting has been postponed owing to a client matter. We are currently establishing how long it will take to resolve, and will confirm the new date shortly.*

对比一下就会发现，变化的不只是动词：*put off* 变成 *postpone*，*find out* 变成 *establish*，*sort out* 变成 *resolve*，*I'll let you know* 变成 *will confirm*，第一句也从主动的第一人称变成了更客观的被动结构。语体是一整套选择，而不是单换一个词。第二封邮件里如果只把 *put off* 换成 *postpone*，其余仍保持聊天口气，读起来依然别扭。

另外，较正式并不等于更好。给同事的第一封邮件如果也写成通知腔，会显得生分；而第二封里夹一句 *something has come up* 又显得随便。关键是让用词和读者匹配，而不是一律追求某一种风格。
