规划**移民雅思**，要按顺序回答三个问题：你的签证接受哪一个版本的雅思？你申请的项目对每一项要求多少分？成绩在你递交申请那天还有效吗？第一个问题是最容易出错的地方：有人花了几个月准备学术类（A 类），结果申请要的是培训类（G 类）；也有人订了普通雅思，英国的类别却要求安全英语语言测试（SELT）。这篇文章带你到官网上逐项核对，概述几个主要目的地在 2026 年 11 月前后大致的要求，并指明该去哪个官方页面确认，再把分数要求变成一份可执行的备考计划。

先声明：本文是语言考试方面的指引，不是法律意见，没有人可以保证签证结果。政策常常变化，下面所有数字都只是“查阅当天的快照”，在付考试费之前请务必到官网核实。

## 第一步：选对移民雅思的考试版本

与移民相关的雅思有三种形式。

**雅思培训类（General Training，常称 G 类）**的听力和口语与学术类相同，阅读使用日常与职场文章，小作文是写信而不是描述图表，大作文在两个版本里都是议论文。加拿大快速通道只接受这个版本。

**雅思学术类（Academic，常称 A 类）**阅读使用学术文章，小作文要描述图表、表格或流程。它为大学入学设计，部分移民体系也接受，但选考之前必须核实。

**UKVI 雅思**是为英国内政部组织的“安全英语语言测试”（SELT）。它只能在获批准的考点考。内容与标准雅思一致，但报名流程、成绩单和 UKVI 标识都不同；如果你为需要 SELT 的英国申请考了普通雅思，这份成绩是不被承认的。

最简单的规则是：在官网上找到明确写出考试名称的那一句话之前，不要订考位。一个很管用的小习惯，是把这句话连同网页地址和查阅日期一起抄进笔记里，以后遇到争议也有据可查。

## 第二步：各国官方页面大致怎么说

下面是我们在 2026 年 11 月前后读到的大致情况，只能当作“该去哪里查、查什么”的提示，不是现行规则。分数、年限和接受的版本都可能调整，请以各国移民部门的官方页面为准（加拿大 IRCC、英国 GOV.UK、澳大利亚内政部、新西兰移民局）。

### 加拿大：G 类与 CLB 对照

加拿大移民局（IRCC）的快速通道语言考试页面写明：雅思只接受培训类，并且不接受“单项重考”（One Skill Retake）。成绩在你完成个人档案时和提交永久居民申请时，都必须不超过两年。成绩过期会导致被拒，所以一月份有效的成绩，可能在邀请到来时已经失效。

加拿大会把你的分数换算成各项的加拿大语言基准（CLB）等级。对培训类，我们读到的换算表大致是这样的（以 IRCC 当前页面为准）：

| CLB | 口语 | 听力 | 阅读 | 写作 |
|---|---|---|---|---|
| 7 | 6.0 | 6.0 | 6.0 | 6.0 |
| 8 | 6.5 | 7.5 | 6.5 | 6.5 |
| 9 | 7.0 | 8.0 | 7.0 | 7.0 |

请注意，各项的门槛并不一样：要达到 CLB 9，听力要 8.0，其他三项只要 7.0，所以每项都是“7.5”的均衡成绩，不一定在每一项都得到相同的 CLB。联邦技术移民页面把 CLB 7 列为第一语言积分表里能够合格的最低等级；其他项目（技工类、加拿大经验类、省提名）各有各的最低要求，请读你申请的那一个。

### 英国：UKVI 雅思与 CEFR B2

英国政府网站的技术工人签证“英语知识”页面写明，你需要在阅读、写作、口语、听力四项都证明达到 CEFR B2 以上。部分续签或特殊情形的要求可能不同，请看官方页面。证明方式包括英国学校的资格证书、符合评估要求的英语授课学位，或者安全英语语言测试。部分国籍的公民和已通过专业机构英语评估的特定专业人员，可能可以免于证明，是否适用于你，请查官方页面。

SELT 指引把 UKVI 雅思列为认可的考试，并说明只能在批准的机构和考点参加，成绩自颁发之日起两年有效。要考哪个等级、哪个版本（学术或培训），取决于你的签证路线，所以请打开你那类签证的指引和认可考试名单。配偶、父母、定居和入籍类申请，可能只需要口语和听力的测试，这会改变你应该订哪一种。

### 澳大利亚：按各项分级

澳大利亚内政部用“胜任（competent）、熟练（proficient）、优秀（superior）”来描述英语水平。该部门页面把这三个等级对应到雅思四个组成部分的最低分，我们读到的是每项 6、7、8 分。该部门自己的例子说，最低的那一项决定你的等级，即使总分看起来更高。

成绩的有效回溯期取决于具体签证子类别，全程在线的考试（包括线上雅思）据我们读到的说明不被接受。不同签证的积分和所需等级不同，请同时打开内政部的英语语言页面和你所属子类别的页面。这一段的澳大利亚数字我们没能在实时页面上完整核对，订考位之前请务必自己再确认。

### 新西兰：主申请人 6.5

新西兰移民局关于技术居留签证的页面，写的是主申请人总分 6.5 或以上，学术类或培训类均可，并接受单项重考。考试必须在考场现场参加，申请时成绩不能超过两年。新西兰的英语语言要求近年有过修订，依赖这一段之前，请先到移民局当前页面确认分数、年限和接受的考试。

### 美国：先看你的表格怎么写

美国大多数移民类别并不像上面几个国家那样要求雅思分数，英语通常在具体流程里评估，例如入籍面谈。如果美国的雇主、大学或执业机构要求雅思，他们会告诉你版本和分数，按他们的说明办，并在 uscis.gov 上查阅你所属类别的表格说明。

## 第三步：留意有效期和“一次考齐”的问题

有两件事悄悄毁掉过很多申请。

**有效期。**上面这些体系大多看的是考试日期，而不是订考日期。两年很常见（加拿大、英国、新西兰），澳大利亚则通常看更长的回溯期，取决于签证。请从你预计递交申请的那天往回数，不要从考试那天往后算。如果你在等邀请，就要预留重考的窗口。

**合并成绩。**有些体系允许单项重考；加拿大快速通道不接受雅思单项重考。其他体系可能接受，所以千万不要想当然。如果你只在某一项差半分，你申请的项目对重考的规定，决定了你是只付一项的费用，还是要重新考整场。

中国考生还要多留一个心眼：很多人通过中介或培训机构的“经验”选考试类型，可那些经验可能来自几年前的政策。凡是别人说“G 类就行”或“A 类都能用”，都请你自己回到官网，找到那一句原文。

## 第四步：把要求变成目标

把你的目标写成四个数字，而不是一个：听力、阅读、写作、口语；然后写下你目前每一项的水平。真正要紧的差距，几乎总是一项，而不是平均分。

| 技能 | 官网页面上的目标 | 目前水平 | 差距 |
|---|---|---|---|
| 听力 | | | |
| 阅读 | | | |
| 写作 | | | |
| 口语 | | | |

第一列照你自己项目的页面填，其余留给一次诚实的练习测试。对网上的“分数预测器”要保持警惕：它只是估算，不是官方成绩，真正算数的只有考官评分。一次在真实条件下的限时模拟，比任何小测验都更适合做起点。要弄清是哪一项拖了后腿，可以看看[雅思备考时间表：4 周、8 周、12 周](/zh/blog/ya-si-bei-kao-shi-jian-biao-4-zhou-8-zhou-12-zhou/)里诊断和错误本的做法。

接着把时间和差距对上。听力差半分和写作差半分，需要的功夫是不同的：听力靠每天短时间听写和题型练习，写作靠对完整答案的反馈。如果你有 12 周，常见的分配是前三周诊断和打基础，中间六周集中在最弱的两项，最后三周做完整限时练习。如果有半年，可以更耐心地积累词汇和语法范围，路线可以参考[雅思自学备考规划](/zh/blog/ya-si-zi-xue-bei-kao-gui-hua-cong-ling-dao-6-5/)。

## 如果你要考 G 类，备考重点会变

如果你的项目要求 G 类，就要把一部分精力放在学术类考生完全不会遇到的任务上。写作 Task 1 是一封信，语气和内容同样计分：给房东投诉和给同事道谢，用的语域完全不同。很多中国考生习惯背“万能开头”，结果写给朋友的信也用了很正式的套话，这一点会被扣分。阅读方面，你会遇到通知、广告和职场文件，要练习快速扫读找细节，可以先看[雅思阅读定位技巧](/zh/blog/ya-si-yue-du-skimming-scanning/)。

![](media:@s2 "培训类书信题按语气分组，并附有高分范文可对照自己的信")

大作文的结构在两个版本里是共用的，所以[雅思写作 Task 2 模板](/zh/blog/ya-si-xie-zuo-task-2-mo-ban/)对你同样适用。口语在所有版本里都是同样的三个部分，建议早点读[雅思口语技巧](/zh/blog/ya-si-kou-yu-ji-qiao/)，因为不少移民考生丢分，并不是词汇不够难，而是在时间压力下流利度出了问题。

## 自我检查

1. 一位加拿大快速通道申请人拿到学术类雅思，四项都是 7.0，被接受吗？
2. 订考位之前，应该按什么顺序检查？
3. 英国技术工人路线需要 SELT，英国政府 SELT 页面列出的是哪一种雅思？
4. 澳大利亚的申请人听力、阅读、写作各 8.0，口语 6.5，按我们查阅的页面，这个成绩是否达到“熟练”（每项 7 分）？
5. 成绩单日期是 2025 年 3 月 3 日，按两年规则大致用到什么时候？

### 答案

1. **不被接受。**IRCC 页面写明快速通道只接受培训类，学术类在这里不算数。
2. **先看版本，再看每项分数，最后看有效期。**先订再查，是人们最后不得不重考的原因。
3. **UKVI 雅思。**标准的雅思成绩单不是 SELT。
4. **没有达到。**最低的一项决定等级，口语 6.5 把这个成绩留在“胜任”（6 分），即使另外三项是 8.0。
5. **大约用到 2027 年 3 月 3 日。**真正重要的是递交时成绩仍然有效，所以要从申请日倒着规划。

## 常见问题

### G 类比 A 类容易吗？

只是不同，不一定更容易。G 类阅读的文章更日常，写信在内容上比描述图表简单，但分数标准相同，写作和口语都按同样的四项标准评分。请选签证要求的版本，而不是你觉得容易的版本。

### 移民用的雅思成绩有效期多久？

取决于体系。我们查阅的页面上，加拿大、英国和新西兰用的是两年，澳大利亚通常回溯更长，取决于签证。请始终从你预计递交申请的日期往回数。

### 可以考线上版或居家版雅思吗？

不要想当然。澳大利亚表示全程远程监考的考试不被接受，新西兰要求现场考试，英国要求在批准的考点参加 SELT。订考位之前请查看你那类签证的页面。

### 每个国家都要单独考一次吗？

不一定。如果版本和分数符合，并且成绩对每个体系仍在有效期内，一份成绩可能满足不止一个体系。但规则不同，例如快速通道只接受 G 类，所以每一个都要单独确认。
