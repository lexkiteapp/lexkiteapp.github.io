*rice*（ご飯）と言ったつもりが、*lice*（シラミ）と受け取られて聞き返された。英語の l と r の発音でつまずくのは、日本語の「ラ行」が l でも r でもない、第三の音だからです。ラ行は舌先で上の歯ぐきを一瞬はじく音で、英語の /l/ とも /r/ とも舌の動きが違います。逆に言えば、2つの音の「舌の置き場所」を体で覚えてしまえば、大人からでも十分に言い分けられるようになります。

以下では、まず日本語のラ行と英語の /l/ /r/ の違いを整理し、次に舌と唇の具体的な形、聞き分けの練習に使えるミニマルペア（1音だけ違う単語の組）、そして日本人に多い「カタカナ発音」の背景にある母音の挿入とリズムの違いまで順に説明します。発音記号に慣れていない方も、記号は最小限にしてありますので安心して読み進めてください。

## 日本語のラ行は /l/ でも /r/ でもない

日本語の「ら・り・る・れ・ろ」を言うとき、舌先は上の歯ぐき（前歯の付け根の少し後ろ）に「トン」と一瞬だけ触れて、すぐ離れます。音声学ではこれを「はじき音」と呼び、記号では [ɾ] と書きます。英語の *water* をアメリカ英語で速く言ったときの「t」（ワラに近い音）が、ほぼこの音です。

英語の2つの音と比べると、違いがはっきりします。

| 音 | 舌先 | 息の通り道 | 長さ | 例 |
|---|---|---|---|---|
| 日本語ラ行 [ɾ] | 歯ぐきに一瞬触れて離れる | 中央を一瞬ふさぐ | とても短い | 「ラーメン」 |
| 英語 /l/ | 歯ぐきに**押し当てたまま** | 舌の**両脇**から出る | 伸ばせる | *light*, *long* |
| 英語 /r/ | どこにも**触れない** | 舌の上を通る | 伸ばせる | *right*, *wrong* |

ポイントは「触れる時間」です。ラ行は一瞬だけ触れる、/l/ はしっかり触れ続ける、/r/ はまったく触れない。日本人の l と r が同じに聞こえてしまうのは、どちらもラ行の「一瞬触れる」動きで代用しているからです。

## 英語のlとrの発音を正しく出すコツ

### /l/：舌先を歯ぐきに押しつけたまま声を出す

1. 舌先を上の前歯の付け根（歯ぐき）にぴったり当てます。
2. その状態のまま「ウー」と声を出します。息が舌の両脇から抜けていくのを感じてください。
3. 1秒ほど伸ばしてから、舌を離して母音につなげます。「（ンー）ライト」のように、/l/ の部分を少し長めに言うのが練習のコツです。

鏡を見て、舌先が歯ぐきに当たっているのが見えれば合格です。*lemon*、*lunch*、*glass* などで試してみましょう。

### /r/：舌をどこにも触れさせず、唇を少し丸める

1. 唇を軽く前に突き出して、小さく丸めます（「ウ」の口に近い形）。
2. 舌先を少し持ち上げて奥へ引きます。ただし、上あごや歯ぐきには**絶対に触れさせません**。
3. その形のまま「ウー」と声を出すと、こもったような /r/ の響きになります。

コツは、出だしに小さな「ゥ」を入れるつもりで言うことです。*right* を「ゥライト」、*red* を「ゥレッド」と言うと、舌が歯ぐきに当たりにくくなります。舌を奥に丸める人もいれば、舌の中ほどを盛り上げる人もいますが、どちらでも「触れない」ことさえ守れば英語の /r/ に聞こえます。

### 語末の l と r は別の音に変わる

単語の最後や子音の前に来る l は、舌の奥も持ち上がる「暗い L」（記号 [ɫ]）になり、日本人の耳には「ウ」や「オ」に近く聞こえます。*milk* /mɪlk/ は「ミルク」より「ミウク」、*feel* /fiːl/ は「フィーゥ」に近い響きです。ただし、舌先は歯ぐきに当てておくのが基本です。

語末の r は、アメリカ英語では *car* /kɑːr/、*bird* /bɝːd/ のように直前の母音に r の響きが混ざります。イギリス英語の標準的な発音では、語末の r は通常発音せず、*car* は /kɑː/ になります。どちらかに統一して練習すれば十分です。

## ミニマルペアで聞き分けと言い分けを練習する

1音だけが違う単語の組を「ミニマルペア」と言います。l と r の練習では、次のような組が定番です。

| /l/ | /r/ | ポイント |
|---|---|---|
| *light*（光） | *right*（右・正しい） | 語頭 |
| *lead*（導く） | *read*（読む） | 語頭 |
| *long*（長い） | *wrong*（間違った） | wr- は /r/ |
| *collect*（集める） | *correct*（正しい） | 語中 |
| *glass*（ガラス） | *grass*（草） | 子音のあと |
| *fly*（飛ぶ） | *fry*（揚げる） | 子音のあと |
| *play*（遊ぶ） | *pray*（祈る） | 子音のあと |
| *alive*（生きている） | *arrive*（到着する） | 語中 |

練習の順番は「聞き分け → 言い分け → 文の中で使う」が効率的です。

1. **聞き分け**：音声を聞いて、どちらの単語かを答えます。最初は正答率が5割程度でも心配いりません。
2. **言い分け**：自分の声を録音し、相手に聞いてもらう、または採点機能でどちらに聞こえるかを確かめます。
3. **文で使う**：*Turn right at the light.*（信号を右に曲がって）や *I'll correct it and collect the papers.*（直してから書類を集めます）のように、両方の音が入った短い文を作って言います。

*glass* や *fly* のように子音と l/r が続く組（クラスター）は特に難しいので、まず前の子音を外して *lass*、*rass* のように l/r の部分を長く伸ばして練習し、慣れたら g や f をつけていきましょう。

## カタカナ発音の正体：母音の挿入とリズムの違い

l と r が言えるようになっても、まだ「日本人っぽい」と言われる場合、原因は個々の音よりも**母音の挿入**と**リズム**にあることが多いです。

### 子音のあとに母音を足してしまう

日本語の音は、基本的に「子音＋母音」で1つのまとまり（モーラ）になっています。そのため、英語の子音だけの部分にも、無意識に母音を足してしまいます。

| 英語 | 実際の音節数 | カタカナ読み | モーラ数 |
|---|---|---|---|
| *strike* | 1 | ストライク（su-to-ra-i-ku） | 5 |
| *milk* | 1 | ミルク（mi-ru-ku） | 3 |
| *glass* | 1 | グラス（gu-ra-su） | 3 |
| *world* | 1 | ワールド（wa-a-ru-do） | 5 |

*glass* を「グラス」と読むと、g のあとに「ウ」が入るため、l の前に母音が挟まり、英語の耳には別の単語のように聞こえます。練習では、子音のあとで口を「ウ」の形にしない、息だけで次の音へ移ることを意識してください。

### モーラのリズムと強勢のリズム

日本語は1モーラずつほぼ同じ長さで刻む言語です。一方、英語は強く読む音節（強勢）がほぼ一定の間隔で現れ、そのあいだの弱い音節は短く、あいまいに発音されます。

たとえば *I want to go to the station.* では、強く読むのは *want*、*go*、*sta-* くらいで、*to* や *the* は弱く短くなります。日本語のリズムで全部を同じ強さで読むと、1つ1つの音が正しくても通じにくくなります。単語では *banana* /bəˈnɑːnə/（米）は「バ・ナ・ナ」と均等にではなく「バ**ナー**ナ」のように、真ん中だけを強く長く読み、前後は弱く短くします。

このリズムを身につけるには、お手本の音声に重ねて話す[シャドーイングのやり方](/ja/blog/shadowing-yarikata/)が効果的です。発音が評価されるTOEIC Speakingを受ける人は、[TOEIC スピーキング対策のコツ](/ja/blog/toeic-speaking-kotsu/)もあわせて読んでみてください。l と r を単語単位で直したら、次は文単位でリズムごと真似する段階に進みましょう。

## lとr以外に日本人がつまずきやすい音

l と r と同じく、日本語にない音や区別のない音はいくつかあります。代表的なものを一覧にしておきます。

| 音のペア | 例 | 日本人に多い誤り | 直し方 |
|---|---|---|---|
| /θ/ と /s/ | *think* / *sink* | 「シンク」と言う | 舌先を上下の歯で軽くはさみ、息を出す |
| /ð/ と /z/ | *then* / *Zen* | 「ゼン」と言う | /θ/ と同じ形で声を出す |
| /v/ と /b/ | *very* / *berry* | 「ベリー」と言う | 下唇に上の前歯を軽く当てる |
| /f/ と /h/ | *fat* / *hat* | 「フ」を両唇の音 [ɸ] で代用する | 下唇に上の前歯を当て、すき間から息を出す |
| /s/ と /ʃ/ | *see* / *she* | *see* が「シー」になる | /s/ は舌先を歯ぐきに近づけ、唇を横に引く |
| /iː/ と /ɪ/ | *sheep* / *ship* | 長さだけで区別する | /ɪ/ は口の力を抜き、「イ」と「エ」の間 |

最後の行のように、母音は長さだけでなく口の形も違います。*ship* の /ɪ/ は、日本語の「イ」より少し口が緩んだ音です。

単語を覚える段階から正しい音で覚えておくと、あとから直す手間が省けます。音声とセットで覚える方法は[英単語の覚え方](/ja/blog/eitango-oboekata/)で詳しく紹介しています。お子さんに英語の絵本を読む保護者の方は、カタカナで読み方を書かない工夫も含めて[おうち英語の始め方](/ja/blog/ouchi-eigo-hajimekata/)を参考にしてください。

## 確認問題：lとrを見分けられますか

1. 舌先を歯ぐきに当てたまま声を出すのは、/l/ と /r/ のどちらですか。
2. *wrong* の最初の子音は /l/ と /r/ のどちらですか。
3. *glass* を「グラス」と読むと、英語らしく聞こえにくい理由は何ですか。
4. アメリカ英語の *bird* と、イギリス英語の標準的な *bird* の違いは何ですか。
5. *I want to go to the station.* で、弱く短く読まれるのはどの語ですか（2つ）。

**答えと解説**

1. **/l/**。/r/ は舌がどこにも触れません。
2. **/r/**。wr- で始まる単語の w は読みません（*write*, *wrap* も同じ）。
3. **g のあとに母音「ウ」が入るから**。英語の *glass* は1音節で、g から l へ母音なしで移ります。
4. **r の響きの有無**。アメリカ英語では /bɝːd/ と r の響きが混ざり、イギリス英語では /bɜːd/ と r を発音しません。
5. **to と the**。英語は強勢のある語を中心にリズムを作るため、機能語は弱くなります。

## よくある質問

### 大人になってからでも l と r は聞き分けられるようになりますか？

なります。最初はほとんど区別できなくても、ミニマルペアで「どちらの音か」を答える練習を毎日少しずつ続けると、正答率は上がっていきます。自分で正しく言えるようになると、聞き分けも楽になるので、聞く練習と言う練習を並行するのがおすすめです。

### ラ行のまま話しても通じますか？

文脈があれば通じることは多いです。ただし *rice* と *lice*、*correct* と *collect* のように、取り違えると意味が大きく変わる場面もあります。すべてを完璧にする必要はありませんが、よく使う単語から優先して直していきましょう。

### アメリカ英語とイギリス英語、どちらの r を練習すべきですか？

語頭の r（*right*, *red*）はどちらも同じ音なので、まずはここから練習してください。語末の r を発音するかどうかは、聞くことの多い英語や、受ける試験に合わせて選べば問題ありません。大切なのは一つに決めて、ぶれないことです。

### 発音記号は覚えたほうがいいですか？

全部を暗記する必要はありませんが、/l/ /r/ /θ/ /ɪ/ など自分が苦手な音の記号だけでも読めると、辞書で正しい音を確認できるようになります。カタカナでは表せない違いを知るための道具だと考えてください。
