過去形・過去分詞の **ed 発音**は、つづりはいつも同じ -ed なのに、実際の音は **/t/・/d/・/ɪd/ の3種類**に分かれます。中学校で「edは『ド』と読む」と覚えた人は多いかもしれませんが、実は *worked* は「ワークド」ではなく /wɜːkt/、*asked* は「アスクド」ではなく /æskt/ です。カタカナで覚えると、1音節の単語が3〜4音節に増えてしまい、ネイティブには *work* と *worked* の区別どころか、どの単語なのかさえ伝わりにくくなります。

この記事では、edの発音を決める3つのルール、無声音と有声音の簡単な見分け方、日本人が間違えやすい単語、そしてリスニングにも効く練習方法を、練習問題つきで解説します。

## ed 発音の3つのルール

{{diagram: d1 | 動詞の最後の「音」（つづりではなく音）で、edの発音が決まる}}

edの発音は、**元の動詞の最後の音**で決まります。つづりではなく「音」であることがポイントです。

**ルール1：最後の音が /t/ か /d/ → /ɪd/（イッド）**
- *want → wanted*（ウォンティッド）
- *need → needed*
- *decide → decided*
- *visit → visited*, *start → started*, *end → ended*

このときだけ、音節が1つ増えます。*want* は1音節、*wanted* は2音節です。

**ルール2：最後の音が無声音 → /t/（ト）**
- *stop → stopped* /stɒpt/
- *work → worked* /wɜːkt/
- *wash → washed* /wɒʃt/
- *watch → watched*, *laugh → laughed*, *kiss → kissed*, *fix → fixed*

音節は増えません。*stopped* は「ストップト」ではなく、/stɒp/ の最後に小さく /t/ を添えるだけです。

**ルール3：最後の音が有声音・母音 → /d/（ド）**
- *play → played* /pleɪd/
- *call → called*
- *live → lived*
- *clean → cleaned*, *open → opened*, *study → studied*

こちらも音節は増えません。「プレイド」と2拍で言うより、*play* の最後に軽く /d/ を付ける感覚です。

## 無声音と有声音の見分け方

「無声音」「有声音」という言葉が難しく感じたら、**のどに手を当てて**確認してみましょう。

- /s/（スー）、/f/（フー）、/k/、/p/、/ʃ/（シー）を出すと、のどは**震えません** → 無声音。
- /z/（ズー）、/v/（ヴー）、/m/、/n/、/l/ や母音を出すと、のどが**震えます** → 有声音。

無声音で終わる主な音は次の6つです：**/p/ /k/ /s/ /ʃ/ /tʃ/ /f/**。これに当てはまれば ed は /t/、/t/ と /d/ 以外の残りはすべて /d/ と覚えれば十分です。

注意したいのは、**つづりではなく音**で判断することです。
- *laugh* はつづりが gh でも、音は /f/ → *laughed* /lɑːft/
- *fix* は x で終わるが、音は /ks/ → *fixed* /fɪkst/
- *bake* は e で終わるが、音は /k/ → *baked* /beɪkt/

## カタカナ発音が通じにくい理由

{{diagram: d2 | カタカナで読むと母音が増えて音節が多くなり、別の単語に聞こえることがある}}

日本語は基本的に「子音＋母音」で1拍を作るため、子音だけで終わる音に母音を足してしまう癖があります。*worked* を「ワ・ー・ク・ド」と読むと、/k/ の後と /d/ の後に「ウ」「オ」の母音が入り、1音節の単語が4拍になります。

この結果、次のような問題が起こります。

- **過去形が聞き取ってもらえない**：*I worked* と言ったつもりが、*I work* や別の単語に聞こえる。
- **リズムが崩れる**：英語は強弱のリズムで話す言語なので、余計な母音が入ると文全体がぎこちなくなる。
- **リスニングで聞き取れない**：自分が「ワークド」と思っている単語を、ネイティブは /wɜːkt/ と一瞬で言うので、聞いても気づけない。

改善のコツは、**最後の /t/・/d/ を「舌の位置だけ」で終える**ことです。舌先を上の歯ぐきに当てて、息をほとんど出さずに止めます。特に文の途中では、*I worked hard* の /t/ はほとんど聞こえないくらい弱くなります。

## 日本人が間違えやすいed 発音の単語

| 単語 | よくある誤り | 正しい発音のポイント |
|---|---|---|
| asked | アスクド | /æskt/、skt の子音が3つ続く |
| liked | ライクド | /laɪkt/、1音節 |
| helped | ヘルプド | /helpt/、l の後は舌を上げたまま |
| decided | ディサイド | /dɪˈsaɪdɪd/、ed をしっかり1音節 |
| needed | ニード | /ˈniːdɪd/、短くすると現在形に聞こえる |
| relaxed | リラックスド | /rɪˈlækst/、x の /ks/ ＋ /t/ |
| changed | チェンジド | /tʃeɪndʒd/、1音節 |

特に注意したいのが *asked* です。/s/・/k/・/t/ と子音が3つ続くため、日本人には非常に言いにくい音です。まず *ask* をゆっくり言い、最後に舌先を歯ぐきに当てて止める練習をしましょう。

逆に、*decided* や *needed* のような /ɪd/ の単語は、edを弱く言いすぎると現在形に聞こえてしまいます。こちらは音節をしっかり1つ増やすのがコツです。

## 形容詞として使われるedの例外

いくつかの -ed 形容詞は、ルールと関係なく /ɪd/ で発音します。

- *a **naked** man* /ˈneɪkɪd/
- *a **wicked** plan* /ˈwɪkɪd/
- *my **beloved** dog* /bɪˈlʌvɪd/
- *an **aged** parent* /ˈeɪdʒɪd/（「年老いた」の意味の場合）
- *a **learned** professor* /ˈlɜːnɪd/（「博識な」の意味の場合）

ただし、動詞として使うときは通常のルールに従います：*He aged quickly* /eɪdʒd/、*I learned a lot* /lɜːnd/。数は少ないので、見かけたら個別に覚えれば十分です。

## ed 発音を身につける練習方法

**1. 3つの箱に分けて音読する。** 毎日5語ずつ過去形を書き出し、/t/・/d/・/ɪd/ の3グループに分類してから音読します。分類する作業が、ルールを自然に定着させます。

**2. 文の中で練習する。** 単語だけでなく、*I worked late yesterday.* *She asked a question.* *We decided to stay.* のように短い文で言いましょう。過去形と現在完了の使い分けもあわせて確認したい人は、[現在完了と過去形の違い](/ja/blog/genzai-kanryou-kakokei-chigai/)を参考にしてください。

**3. シャドーイングで「消える音」に慣れる。** ネイティブの音声を聞きながら少し遅れてまねると、文の途中で /t/・/d/ がほとんど聞こえなくなることに気づきます。やり方は[シャドーイングのやり方](/ja/blog/shadowing-yarikata/)で詳しく紹介しています。

**4. 発音記号で確認する。** つづりに引きずられやすい単語は、辞書で発音記号を確認するのが一番確実です。Lexkiteの[発音ライブラリ](/app/#/pron)では、/t/・/d/ を含む子音や母音を一つずつ聞いて練習し、採点で確認できます。

![](media:@s2 "発音ライブラリでは母音と子音を一つずつ聞き、例語で練習して採点できる")

**5. 受動態でも同じルール。** 過去分詞の *-ed* も同じ発音です：*The window was opened* /d/、*The package was delivered* /d/、*The meeting was cancelled* /d/、*The report was finished* /t/。[英語の受動態](/ja/blog/eigo-judoutai/)を練習するときも、ed の音を意識しましょう。

LとRの区別など、ほかの日本人が苦手な音もあわせて練習したい人は、[LとRの発音](/ja/blog/l-to-r-hatsuon/)も読んでみてください。リスニング全般の上達法は[英語リスニング上達法](/ja/blog/eigo-listening-joutatsu/)にまとめています。

## 練習問題：edの発音を分類しよう

次の単語のedを /t/・/d/・/ɪd/ に分類してください。

1. jumped
2. arrived
3. painted
4. finished
5. enjoyed
6. added
7. missed
8. answered
9. hoped
10. invited

### 解答

1. jumped — **/t/**（p は無声音）
2. arrived — **/d/**（v は有声音）
3. painted — **/ɪd/**（t で終わる）
4. finished — **/t/**（sh /ʃ/ は無声音）
5. enjoyed — **/d/**（母音で終わる）
6. added — **/ɪd/**（d で終わる）
7. missed — **/t/**（s は無声音）
8. answered — **/d/**（r の音は有声音）
9. hoped — **/t/**（p は無声音。つづりの e は発音しない）
10. invited — **/ɪd/**（t で終わる）

8問以上正解なら、ルールは身についています。4と9を間違えた人は「つづりではなく音で判断する」ことを、3・6・10を間違えた人は /ɪd/ のときだけ音節が増えることを、もう一度確認しましょう。

## よくある質問

### edの発音を間違えると通じませんか？

文脈で補ってもらえることも多いですが、*worked* を「ワークド」と言うと音節が増えて聞き取りにくくなります。特に電話や会議など、表情が見えない場面では誤解の原因になりやすいです。

### s・esの発音にもルールはありますか？

はい。/s/・/z/・/ɪz/ の3種類があり、edと同じように最後の音（無声音か有声音か）で決まります。*cats* /s/、*dogs* /z/、*buses* /ɪz/ です。

### アメリカ英語とイギリス英語で違いはありますか？

ルール自体は同じです。ただし、*learned* と *learnt*、*dreamed* と *dreamt* のように、イギリス英語ではつづりが -t になる不規則形が使われることもあります。

### 子どもに教えるときのコツは？

「t か d で終わる動詞だけ『イッド』」というルール1を最初に教え、残りは「のどに手を当てて震えるか」で /t/ と /d/ を分けるゲームにすると覚えやすいです。
