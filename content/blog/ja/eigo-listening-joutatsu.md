英語のリスニングを上達させる一番の近道は、自分のレベルに合った短い音声を「目的を変えながら何度も」集中して聞き、その合間に、もっとやさしい英語をたくさん聞くことです。難しすぎる音声を何時間も聞き流しても、脳がつかめる手がかりがないため、ほとんど力になりません。この記事では、なぜそう言えるのかを説明したうえで、今日からそのまま使える練習手順を紹介します。

## 知っている単語なのに聞き取れない4つの原因

「音声だけだと分からないのに、スクリプトを見ると知っている単語ばかり」。日本人学習者から最もよく聞く悩みです。原因はたいてい、次の4つのどれかにあります。

**1. 単語を「文字」と「カタカナの音」で覚えている。** 学校英語では、読んで訳す練習が中心になりがちです。すると頭の中には、つづりと、カタカナに置き換えた読み方が保存されます。*comfortable* を「カンフォータブル」と覚えていると、実際の /ˈkʌmftəbl/（カンフタボー に近い音）が来ても、同じ単語だと気づけません。

**2. 話し言葉には単語の切れ目がない。** 文字では単語と単語の間にスペースがありますが、音声にはありません。*Let me check it out.* は「レミ・チェケラウ」のように一続きで聞こえます。1語ずつは知っていても、つながった形を聞いた経験がなければ、別の言葉に聞こえてしまいます。

**3. 日本語と英語ではリズムの仕組みが違う。** 日本語は「タ・マ・ゴ」のように、ほぼ同じ長さの拍（モーラ）を等間隔で刻みます。英語は強く読む音節に力を集め、それ以外を弱く短く流します。すべての音がはっきり聞こえるのを待っていると、半分近くの音節はもともと弱いので、聞き逃したと感じてしまいます。

**4. 頭の中で和訳し、後ろから戻って理解している。** 「関係代名詞の後ろから訳す」読み方に慣れていると、聞くときも文の最後を待ってから日本語に組み立て直そうとします。その間に次の文が流れていき、話についていけなくなります。これは記憶力の問題ではなく、英語を英語の語順のまま処理する練習が足りないだけです。

どの原因が自分に当てはまるかを知ることが、どんなテクニックよりも大切です。原因ごとに効く練習が違うからです。

## ボトムアップとトップダウン：2つの聞き方

言語教育の分野では、リスニングを2つの処理が同時に働くものとして説明することがよくあります。

| | ボトムアップ処理 | トップダウン処理 |
|---|---|---|
| していること | 音を単語に、単語を文に組み立てる | 状況や背景知識から内容を予測する |
| 頼りにするもの | 音の聞き分け、語彙、文法 | 話題、場面、一般常識 |
| 弱いとどうなるか | 大意は合うが、数字や細部を間違える | 単語は聞こえるのに、言いたいことがつかめない |
| 効く練習 | ディクテーション、音の変化の確認 | 聞く前の予測、要点だけを聞く練習 |

上手な聞き手は、両方を同時に使っています。「次はこんな話が来そうだ」と予測しながら（トップダウン）、実際の音で予測を確かめる（ボトムアップ）のです。

試験対策を中心に勉強してきた人は、キーワードをいくつか拾って残りを推測する、トップダウン寄りの聞き方になりやすい傾向があります。設問の選択肢を先に読む習慣はTOEICのPart 3・4で役立ちますが、数字、人名、*hardly* のような小さな否定語が答えを左右する問題では、推測だけでは失点します。このタイプの人は、ディクテーション（書き取り）の時間を増やしましょう。

逆に、単語は1つずつ聞こえるのに話の流れがつかめない人は、聞く前に「タイトルからすると、どんな話が出てきそうか」を10秒考える習慣をつけると効果的です。

## 聞き流しだけでは上達しない：能動的に聞く時間をつくる

**受動的リスニング**は、家事や通勤のあいだに英語を流しておく聞き方です。**能動的リスニング**は、ほかのことをせずに集中し、目的を決めて、止めたり戻したりしながら聞く聞き方です。

聞き流しにも意味はあります。英語のリズムに耳を慣らし、英語に触れる総時間を増やしてくれます。ただし効果があるのは、**大半をがんばらずに理解できるやさしい内容**のときだけです。中学英語の復習段階の人が、大学の講義を聞き流しても、それは雑音と変わりません。

本当に聞き取る力が伸びるのは、能動的に聞いている時間です。どこを聞き間違えたのかを見つけ、直す作業ができるからです。時間の使い方の目安は次のとおりです。

- **忙しい日**：1〜2分の音声を15分、能動的に聞く。
- **余裕があれば**：通勤や家事の時間に、やさしい内容を聞き流す。

## 教材選びは「i+1」：自分に合う音声の見つけ方

言語学者のスティーブン・クラッシェンは、「理解可能なインプット（comprehensible input）」という考え方を示しました。よく「i+1」と書かれ、今の力（i）より少しだけ難しいものが、最も学びになるという意味です。リスニング教材に当てはめるなら、次の3つの質問で確かめられます。

1. 字幕なしで1回聞いて、**大まかな内容**が分かりますか。
2. スクリプトを見たとき、まったく知らない単語は**数えられるほど**しかありませんか。
3. 内容を知ったうえで聞き直せば、**速さについていけ**ますか。

3つとも「はい」なら、その教材はちょうどよいレベルです。「いいえ」が2つ以上なら、やさしい教材に替えるか、再生速度を落としましょう。速度を落とすのはずるではありません。一時的な足場で、慣れたら少しずつ元の速さに戻せばよいのです。

レベル別の目安です。

- **英検準2級〜2級程度（A2〜B1）**：台本のある日常会話、学習者向けの音声教材、英語字幕つきの短い動画など、身近な話題のもの。
- **英検2級〜準1級程度（B1〜B2）**：興味のある分野の対談、ゆっくりめのニュース、TOEICのPart 3・4、IELTSのリスニングのPart 1・2。
- **準1級以上（B2〜C1）**：インタビュー、講義、自然な速さの番組、字幕なしの映画、IELTSのPart 3・4。

英検とCEFRの対応はあくまで大まかな目安なので、上の3つの質問で実際に確かめるのが確実です。

## 英語リスニング上達のための「5回聞き」トレーニング

スクリプトのある1〜3分の音声を1つ選びます。それ以上長いものは選ばないでください。必要なのは長さではなく、深さです。

**1回目：大意をつかむ。** 止めずに、字幕もスクリプトも見ずに聞きます。聞き終えたら「誰が、何について話し、結論は何か」を1文で言うか書きます。聞き取れた単語を3つメモしておきます。

**2回目：細部を聞く。** 今度は止めてもかまいません。数字、名前、理由、具体例をメモします。問題がついている教材なら、ここで解きます。

**3回目：聞き取れない文を書き取る。** うまく聞き取れなかった文を3〜5つ選び、1文ずつ一語一句書き取ります。自信のないところは空欄にし、当てずっぽうで埋めないでください。

**4回目：スクリプトと照らし合わせ、ミスを分類する。** 書き取った文とスクリプトを比べ、間違いを次の表の種類に分けます。この手順が、トレーニング全体の中心です。

**5回目：文字を見ずに聞き、声に出して追いかける。** もう一度通して聞くと、最初よりずっとはっきり聞こえることに驚くはずです。そのあと短い部分を選び、少し遅れて声に出して追いかけます。耳と口が一緒にリズムを覚えていきます。詳しい手順は[シャドーイングのやり方](/ja/blog/shadowing-yarikata/)で解説しています。

![Lexkiteの発音練習画面。フレーズcut down onが表示され、マイクボタンで話すと声で採点される](media:practice-speak "フレーズを声に出して採点を受けると、自分の発音のくせに気づき、聞き取りにも生きてくる")

2〜3日たったら、同じ音声を止めずに1回だけ聞き直します。間隔をあけて聞き直すことで、新しく覚えた音のパターンが反射的に聞き取れるものに変わっていきます。

## 聞き取りミスの分類と直し方

| ミスの種類 | 例 | 直し方 |
|---|---|---|
| 単語そのものを知らない | *reluctant* を知らなかった | 意味と音をセットで覚え、例文を作る |
| 知っているのに音が一致しない | *vegetable* を「ベ・ジ・タ・ブ・ル」と5拍で覚えていた | 発音記号 /ˈvedʒtəbl/ を確認し、声に出して覚え直す |
| 音のつながり・脱落 | *turn it off* が1語に聞こえた | 音の変化のルールを知り、その部分をゆっくり聞き直す |
| 機能語の弱形 | *to*、*and*、*can* が聞こえない | 弱い形 /tə/、/ən/、/kən/ を覚える |
| 速さについていけない | 読めば分かるのに、聞くと流れてしまう | 速度を落として繰り返し、少しずつ上げる |
| 背景知識が足りない | 1文ずつは分かるが、話の筋が追えない | その話題について先に日本語か英語で読む |

2行目は、日本人に特に多いタイプです。*chocolate* は「チョコレート」ではなく /ˈtʃɒklət/（チョクレッ に近い音）、*interesting* は /ˈɪntrəstɪŋ/ のように3音節で発音されることがよくあります。カタカナ語として先に知っている単語ほど、英語の音とのずれが大きく、聞き取りの壁になります。単語を覚える段階から音声で確認しておく方法は、[英単語の覚え方](/ja/blog/eitango-oboekata/)にまとめています。

3行目と4行目は、中級レベルで最も多いミスです。代表的な弱形を知っておくだけでも、聞こえ方が変わります。

- *to* → /tə/：*I need to leave.* の *to* は「タ」のように短く弱い。
- *and* → /ən/ または /n/：*salt and pepper* は「ソルトン・ペパー」のように聞こえる。
- *can* → /kən/：肯定文の *I can come.* では弱く「クン」。否定の *can't* は母音がはっきり残り、強く読まれやすい。
- *of* → /əv/ または /ə/：*a lot of people* は「アラタ・ピーポー」のように聞こえることが多い。

*can* と *can't* の区別は、TOEICでも日常会話でも聞き間違えると意味が逆になる要注意ポイントです。音の強さで聞き分ける意識を持ちましょう。個々の子音、たとえば *right* と *light* で迷う場合は、[英語のlとrの発音](/ja/blog/l-to-r-hatsuon/)で舌の位置から確認できます。

## 1週間のリスニング練習スケジュール例

| 曜日 | 能動的に聞く（15〜20分） | 追加で聞く（時間があれば） |
|---|---|---|
| 月 | 新しい音声で1〜3回目 | 好きな話題のやさしい内容 |
| 火 | 同じ音声で4〜5回目 | 同上 |
| 水 | 新しい音声で1〜3回目 | 同上 |
| 木 | 同じ音声で4〜5回目、月曜の音声を聞き直す | 同上 |
| 金 | 試験形式の問題を1セット解いて採点 | 同上 |
| 土 | 今週の2つの音声を止めずに聞き直す | 映画やドラマ |
| 日 | 休み、または楽しみのための視聴 | |

試験を控えている人は、金曜日を本番と同じ形式で解く日にしましょう。TOEICのリスニングは約45分・100問で、Part 1〜4の4つのパートに分かれています。学習全体の中でリスニングにどれだけ時間を割くかは[TOEIC勉強法](/ja/blog/toeic-benkyouhou/)で、リーディングまで含めた本番の時間の使い方は[TOEIC Part 7の時間配分](/ja/blog/toeic-part7-jikan-haibun/)で解説しています。

## 確認問題：リスニングの基本

1. 大まかな内容は分かるのに、数字や人名をよく間違えます。弱いのはどちらの処理で、どんな練習をすればよいですか。
2. *I'd like a cup of tea.* で弱く読まれやすい単語はどれですか。
3. 毎日2時間、英語ニュースを聞き流していますが、ほとんど分かりません。どんなアドバイスをしますか。
4. 空欄を埋めましょう。*and* の弱形は ___、*to* の弱形は ___ です。
5. 4回目の照らし合わせで、*I'll* を *I* と聞き違えていました。どの種類のミスですか。
6. 能動的に聞く練習で、30分の番組より1〜3分の音声を選ぶのはなぜですか。

**答えと解説**

1. **ボトムアップ処理**が弱い状態です。数字や人名は文脈から推測できないので、1文ずつのディクテーションや、止めながら細部を聞く練習を増やします。
2. ***a*（/ə/）と *of*（/əv/ または /ə/）**です。文の中の機能語は弱く読まれ、強く読まれるのは内容語の *like*、*cup*、*tea* です。
3. 内容が今のレベルに対して難しすぎ、雑音になっています。i+1の考え方でやさしい教材に替え、そのうえで毎日15分は、スクリプトを使って能動的に聞く時間をつくりましょう。
4. **/ən/（または /n/）** と **/tə/** です。
5. **音の短縮・脱落のミス**です。*I'll* の /l/ はとても弱く聞こえます。語彙の問題ではなく音の問題なので、その部分をゆっくり聞き直し、声に出して真似するのが直し方です。
6. 短い音声なら、目的を変えて何度も聞き、ミスを1つずつ分析できるからです。長い番組では1回ざっと聞くだけで時間がなくなり、結局は聞き流しに戻ってしまいます。

## よくある質問

### リスニングの練習は1日どのくらいすればよいですか？

忙しい方なら、能動的に聞く練習を毎日15〜20分続けるのがおすすめです。週末に3時間まとめて聞くより、短くても毎日のほうが耳は慣れていきます。時間に余裕がある日は、やさしい内容を聞き流して英語に触れる量を増やしましょう。

### 字幕はつけたほうがいいですか？

使うタイミングが大切です。1回目は字幕なしで聞き、本当はどれだけ分かっているかを確かめます。そのあと英語字幕やスクリプトで答え合わせをします。日本語字幕は、内容が難しすぎて楽しむことが目的のときだけにしましょう。

### 聞き流しを続けているのに上達しません。どうすればいいですか？

3つの点を見直してください。教材のレベルが合っているか、スクリプトを使って能動的に聞いているか、聞き間違いを分類しているか、です。「聞いても伸びない」ケースの多くは、難しすぎる音声を聞き流すだけで、答え合わせをしていないことが原因です。

### アメリカ英語とイギリス英語、どちらから練習すべきですか？

まずは自分が聞きやすいと感じる発音から始め、慣れてきたらほかの発音にも広げましょう。TOEICやIELTSでは、アメリカ以外の発音も流れることがあるので、ある程度慣れたら複数の発音に触れておくと安心です。
