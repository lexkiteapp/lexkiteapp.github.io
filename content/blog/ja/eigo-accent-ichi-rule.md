英語の単語は、どこを強く読むかで別の単語に聞こえます。幸い、**英語 アクセント 位置 ルール**には、ほぼ当たる決まりがいくつもあります。2音節の名詞は最初、動詞は2番目に置く傾向があり、語尾の形（接尾辞）によって位置が決まる語も多いです。ルールと例外を知っていれば、*de-VEL-op-ment* を *DE-ve-lop-MENT* と読んで通じなかった経験を減らせます。この記事では、日本語話者が特につまずく「カタカナ発音」との違いを軸に、各ルールをIPAつきで説明します。

## 英語のアクセントとカタカナの違い

日本語の「アクセント」は、主に**音の高低**で決まります（橋と箸の違いなど）。一方、英語の語アクセントは、**強く、長く、はっきりした母音**で表されます。ある音節が強く読まれ、ほかの音節は弱く短くなります。強勢のない母音の多くは、曖昧母音 /ə/（シュワー）に弱まります。

{{diagram: d1 | 日本語は「高低」、英語は「強弱と母音の質」で単語を区別します}}

たとえば *banana* /bəˈnɑːnə/ は、真ん中の音節だけが強く、最初と最後は弱い /ə/ です。「バナナ」と3つの拍を同じ強さで読むのとは違います。IPAの ˈ は強勢のある音節の**直前**に付き、ˌ は弱めの第2強勢を表します（例：*education* /ˌedʒuˈkeɪʃn/）。

もう1つの大きな違いは、数える単位です。日本語は拍（モーラ）、英語は音節で数えます。*milk* は英語では1音節ですが、「ミルク」は3拍です。「ストライク」は *strike* の1音節に母音を足して5拍にしています。母音を足す癖があると、英語のリズムが崩れ、アクセントの位置も不明瞭になります。リズム全体の話は[英語の文ストレスとリズム](/ja/blog/eigo-bun-no-stress-rhythm-guide/)で扱っています。

なぜ重要かというと、聞き手は、母音や子音だけでなく**アクセントの形**も手がかりに単語を認識するからです。*ho-TEL* を正しく言えても、*de-SERT*（見捨てる）と *DES-ert*（砂漠）を混同すると別の語に聞こえます。母音を少し間違えるより、アクセントの位置を間違えるほうが通じにくいこともあります。

日本人学習者に多いアクセントの誤りを挙げます。

- *coffee* を「コーヒー」と伸ばして読み、*COF-fee* /ˈkɒfi/ の弱い第2音節まで同じ強さで言ってしまう。
- *energy* を「エネルギー」と4拍で読み、*EN-er-gy* /ˈenədʒi/ の3音節・第1音節の強勢にならない。
- *テクノロジー* の *technology* を *TECH-no-lo-gy* と頭に置く。正しくは *tech-NOL-o-gy* /tekˈnɒlədʒi/。
- *communication* の語尾を強く読み、*com-mu-ni-CA-tion* /kəˌmjuːnɪˈkeɪʃn/ の強勢位置（ca）を外す。
- *マネージャー* の *manager* を *ma-NA-ger* と読む。正しくは *MAN-a-ger* /ˈmænɪdʒə/。

## 英語 アクセント 位置 ルール①：2音節語

### 名詞・形容詞は第1音節が多い

*CI-ty, SUM-mer, LES-son, SIL-ver, BUS-y, QUI-et* のように、最初を強く読むものが多数です。

### 動詞は第2音節が多い

*be-LIEVE, ar-RIVE, sup-PORT, de-FEND, ob-TAIN, in-VITE* のように、動詞は後ろを強く読みます。

### よくある例外

- 名詞で第2音節に置くもの：*ho-TEL* /həʊˈtel/、*ma-CHINE*、*po-LICE*、*ad-VICE*、*de-SIGN*。
- 動詞で第1音節に置くもの：*-en, -er, -ish, -ow, -y* で終わる動詞が多く、*LIS-ten*、*AN-swer*、*FIN-ish*、*BOR-row*、*MAR-ry* などです。

例外も日常語が多いので、すでに知っている語が大半でしょう。初めて見る単語に当てはめるときに、このルールが最も役に立ちます。

## 名詞と動詞でアクセントが動く語

つづりが同じでも、名詞と動詞でアクセントが変わる語があります。名詞は第1音節、動詞は第2音節で、母音も変化します。

| 語 | 名詞 | 動詞 |
|---|---|---|
| import | /ˈɪmpɔːt/ 輸入品 | /ɪmˈpɔːt/ 輸入する |
| export | /ˈekspɔːt/ 輸出品 | /ɪkˈspɔːt/ 輸出する |
| contrast | /ˈkɒntrɑːst/ 対比 | /kənˈtrɑːst/ 対比させる |
| insult | /ˈɪnsʌlt/ 侮辱 | /ɪnˈsʌlt/ 侮辱する |
| refund | /ˈriːfʌnd/ 返金 | /rɪˈfʌnd/ 返金する |
| subject | /ˈsʌbdʒɪkt/ 主題 | /səbˈdʒekt/ 服従させる |

（イギリス英語のIPAです。アメリカ英語では /ɒ/ が /ɑː/ になります。）

すべての語がこのパターンに当てはまるわけではありません。*promise* や *visit* は名詞も動詞も第1音節、*report* や *control* は両方とも第2音節です。

## 接尾辞：長い単語の手がかり

3音節以上の単語は、語尾を見るとアクセントの位置がかなり予想できます。

### グループ1：接尾辞の直前の音節

**-tion、-sion、-ic、-ical、-ity、-ial、-ian、-ious、-ient** が付くと、その直前にアクセントが置かれます。

*com-pe-TI-tion, lo-CA-tion, e-LEC-tric, cre-a-TI-vi-ty, of-FI-cial, con-VE-nient.*

これは英語で最も信頼できるルールの1つで、1つだけ覚えるならこれです。

### グループ2：後ろから3番目の音節

**-graphy、-logy、-cy、-ate（3音節以上）、-ize/-ise、-ify** など。

*ge-OG-ra-phy* /dʒiˈɒɡrəfi/、*tech-NOL-o-gy*、*de-MOC-ra-cy* /dɪˈmɒkrəsi/、*a-POL-o-gize* /əˈpɒlədʒaɪz/、*i-DEN-ti-fy* /aɪˈdentɪfaɪ/。

### グループ3：接尾辞そのものが強い

**-ee、-eer、-ese、-ique** は、その音節が強く読まれます。

*vol-un-TEER* /ˌvɒlənˈtɪə/、*Ja-pa-NESE* /ˌdʒæpəˈniːz/、*ref-u-GEE*、*u-NIQUE* /juˈniːk/。

ここで日本人の英語学習者に大切な単語があります。*Japanese* は最後の *-nese* が強く、*JA-pa-nese* ではなく *Ja-pa-NESE* です。自己紹介で毎回使う語なので、ぜひ直してください。

（*committee* /kəˈmɪti/ は *-ee* で終わりますが、第2音節が強い有名な例外です。）

### グループ4：アクセントを動かさない接尾辞

**-ness、-ment、-ful、-less、-er、-or、-ly、-ing、-ed、-able** は位置を変えません。

*de-VEL-op → de-VEL-op-ment*、*HAP-py → HAP-pi-ness*、*COM-fort → COM-fort-a-ble*。

{{diagram: d2 | 接尾辞を見れば、アクセントの位置が予想できます}}

接頭辞も同様で、*un-, dis-, re-, mis-* は通常、強勢を受けません。*un-HAP-py, dis-a-GREE, re-WRITE*。接頭辞を強くすると、*I said UNlock, not lock.* のように「訂正」の意味に聞こえます。

## 語族でアクセントが移動する

接尾辞の影響で、同じ語族の語でもアクセントが大きく動きます。

- *PHO-to-graph* /ˈfəʊtəɡrɑːf/ → *pho-TOG-ra-pher* → *pho-to-GRAPH-ic*
- *e-CON-o-my* → *e-co-NOM-ic* → *e-CON-o-mist*
- *PO-li-tics* → *po-LIT-i-cal* → *po-li-TI-cian*

アクセントが動くと、母音の質も変わります。強勢を失うと /ɒ/ が /ə/ に弱まります。新しい学術語を覚えるときは、語族をまとめて、各形のアクセントも一緒にメモしてください。

## 複合語・句動詞・13と30

**複合名詞**は最初の部分に強勢を置きます。*BLACK-board, GREEN-house, TOOTH-brush*。*a black BOARD* は「黒い板」というフレーズで、アクセントが違います。

**句動詞**は小辞（副詞・前置詞）を強く読みます。*give UP, turn DOWN, set UP, work OUT*。名詞形は前を強く読みます。*a SET-up, a WORK-out, a TAKE-away*。

**数字の13と30**は、リスニング試験で頻繁に間違えられます。*thir-TEEN* /ˌθɜːˈtiːn/ と *THIR-ty* /ˈθɜːti/ では、語尾の長さが違います。アメリカ英語では *thirty* の *t* がはじくような音になります。TOEIC の[Part 2 のコツ](/ja/blog/toeic-part2-kotsu/)にも通じる大切な聞き分けです。トピック別の単語は、英語のページですが[語彙リスト](/en/vocabulary/)でも確認できます。

## 日本語話者のためのアクセント練習法

1. **IPAの強勢記号を確認する。** 辞書で単語を調べるときは、ˈ の位置を見ます。Lexkite の[辞書](/app/#/dict/photography)では、UK と US のIPAと音声が見られます。IPAの読み方は[IPA 発音記号の一覧](/ja/blog/ipa-hatsuon-kigou-hyou-eigo/)にまとめています。

![](media:@s1 "IPAの強勢記号を確認してから、新しい単語を単語帳に追加しましょう")

2. **メモに強勢を書く。** *de-VEL-op-ment* のように大文字で書くか、下線を引きます。強勢のない単語メモは、目に入るだけで口には入りません。
3. **手でリズムを取る。** 強い音節で机を叩きながら言います。子供っぽいですが効果があります。
4. **フレーズで練習する。** 単語単独のほうが簡単です。*an e-co-NOM-ic ad-VAN-tage* のように、前後とつなげて言います。
5. **録音して確認する。** [発音練習](/app/#/practice/speak)でマイクに向かって言い、スコアを確かめます。個別の音が弱いなら、[発音記号ライブラリ](/app/#/pron)から始めましょう。[シャドーイングのやり方](/ja/blog/shadowing-yarikata/)もおすすめです。

![](media:@s2 "複数音節の単語をマイクに向かって言い、発音のスコアを確認します")

あわせて、[英語の発音練習のコツ](/ja/blog/eigo-hatsuon-renshuu-kotsu/)や[l と r の発音](/ja/blog/l-to-r-hatsuon/)も読んでおくと、単語単位から文単位へ進めます。

## 自己チェック

強く読む音節に印を付けてください。

1. comfortable
2. decision
3. volunteer
4. to refund（動詞）
5. photographer
6. hotel
7. economic
8. thirteen（単独で言う場合）

**答えと解説：**
1. COM-fort-a-ble（-able は動かさない。第1音節）。
2. de-CI-sion（-sion の直前）。
3. vol-un-TEER（-eer 自体が強い）。
4. re-FUND（動詞は第2音節）。
5. pho-TOG-ra-pher（後ろから3番目）。
6. ho-TEL（名詞の例外）。
7. e-co-NOM-ic（-ic の直前）。
8. thir-TEEN（単独では -teen が強く長い）。

## よくある質問

### 辞書でアクセントを確認する方法はありますか？

IPAの ˈ が強勢の位置を示します。ˈ は強い音節の直前に付きます。辞書の音声も一緒に聞き、位置を耳で確認してください。

### カタカナ語と同じ位置でよいですか？

いいえ。カタカナ語は日本語のアクセントとして定着しているので、英語の位置とは異なります。*energy* や *technology* のように、別物として覚え直してください。

### アメリカ英語とイギリス英語でアクセントが違う語はありますか？

あります。*adult* や *cigarette* など、一部の語で位置が異なります。ただし、この記事のルールが当てはまる語がほとんどです。

### ルールを全部覚えないといけませんか？

全部は不要です。-tion や -ic の直前、名詞と動詞のペア、*Japanese* のような -ese の3つから始めれば、大半の語をカバーできます。
