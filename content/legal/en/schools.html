Lexkite for schools

A guide for teachers and school IT administrators: classroom mode, installing the Lexkite Chrome extension for a whole domain, and deploying the web app. Lexkite is free, with no ads for classroom accounts.

1. Classroom mode for teachers

  1. Open lexkite.com/app/#/class and sign in with Google.
  2. Under Classes I teach, type a class name and choose Create class. You get a 6-character join code.
  3. Choose Share to Google Classroom to post the join link to your class stream, or give students the code. Students open the link, sign in and choose Join.
  4. Choose Assign to pick a word list or a practice test (IELTS Listening, IELTS Reading Academic and General Training, TOEIC Listening & Reading). Each assignment has its own Assign in Classroom button, so it can be posted as a Google Classroom assignment with a due date.
  5. The Student progress table shows, for each student, completed assignments, average accuracy, last activity and the best score for each assignment. Choose CSV to download it for your gradebook.

Results are sent automatically when a signed-in student finishes an assigned word-list activity (Test, Match or a quiz with a score) or submits an assigned practice test. Lexkite does not request any Google Classroom permissions: the share button uses Google’s public share link, so no class roster, email address or grade is read from Google.

2. Install the Chrome extension for a whole domain

Extension ID: idalfipabpfcajpkfkifbdlpejcdmfcd · Chrome Web Store: Lexkite

Google Admin console (Chromebooks and managed Chrome):

  1. Sign in to admin.google.com with an administrator account.
  2. Go to Devices → Chrome → Apps & extensions → Users & browsers.
  3. On the left, select the organisational unit (for example Students or Teachers).
  4. Choose the yellow + button → Add from Chrome Web Store, search for Lexkite (or paste the extension ID above) and choose Select.
  5. Set Installation policy to Force install (or Force install + pin to browser toolbar) and choose Save.
  6. Devices pick up the policy at the next sync. To apply it immediately on a test device, open chrome://policy and choose Reload policies.

Windows Group Policy, macOS profiles or Linux JSON policy (Chrome Enterprise Core): add this value to the ExtensionInstallForcelist policy:

idalfipabpfcajpkfkifbdlpejcdmfcd;https://clients2.google.com/service/update2/crx

Permissions the extension uses: read the word you select on a page to show its meaning (access to web pages), store your saved words on the device (storage), review reminders (alarms, notifications), the right-click menu (context menus) and opening a web search for a word (search). It shows no ads and loads no remote code. Details: Privacy Policy, section 13.

3. Deploy the web app

Lexkite is a web app and needs no server or installation at your school. To put it on every student device:

  1. In the Admin console go to Devices → Chrome → Apps & extensions → Users & browsers, choose + → Add by URL.
  2. Enter https://lexkite.com/app/, choose Open in a separate window, then set Force install (optionally pin it to the taskbar or shelf).
  3. To put the class page on student devices, add a bookmark to https://lexkite.com/app/#/class with the Managed bookmarks policy (Devices → Chrome → Settings → Users & browsers).

Allow these addresses if your school filters web traffic: lexkite.com, *.lexkite.com, lexkiteapp.github.io, cdn.jsdelivr.net, lexkite-app.firebaseapp.com, www.gstatic.com, apis.google.com, accounts.google.com, fonts.googleapis.com, fonts.gstatic.com, translate.googleapis.com, api.datamuse.com and challenges.cloudflare.com.

4. Google sign-in for students under 18

Google Workspace for Education blocks users designated as under 18 from signing in to third-party apps that the admin has not configured. To let students sign in to Lexkite:

  1. In the Admin console go to Security → Access and data control → API controls → Manage third-party app access.
  2. Choose Configure new app, search for Lexkite (sign-in page lexkite-app.firebaseapp.com) and select it.
  3. Choose the organisational unit and set access to Trusted. Lexkite only asks for basic profile information (name, email address and photo of the student’s own account) and no access to Google Drive, Gmail or Classroom data.

If you cannot find the app, contact support@lexkite.com and we will send you the OAuth client ID.

5. Student privacy

  • Teachers see only the display name a student types when joining (we recommend a first name and class) and that student’s results for assigned work. Email addresses and photos are never shown to teachers or classmates.
  • No ads for classroom accounts; student data is never sold or used for advertising or profiling.
  • Teachers can remove a student or delete a class at any time, which deletes the related data immediately. Students can leave a class, and deleting an account deletes all of its data.
  • COPPA and FERPA: see Privacy Policy, section 10. For a data processing agreement or a privacy questionnaire, contact support@lexkite.com.
